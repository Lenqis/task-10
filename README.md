# Mini Todo App

Небольшое приложение «Список задач» на чистом JavaScript.

## Задача
Собрать приложение со списком задач:
- поле ввода + кнопка «Добавить»;
- у каждой задачи чекбокс/переключение «выполнено» и кнопка «Удалить»;
- выполненные задачи зачёркнуты;
- фильтры: «Все», «Активные», «Выполненные».

## Что реализовано
- Добавление задач с валидацией (пустые строки и пробелы игнорируются).
- Переключение статуса по клику — в обе стороны.
- Удаление задач.
- Отрисовка списка из массива.
- Зачёркивание выполненных через CSS-класс.
- Фильтрация без мутации исходного массива.
- Подсветка активного фильтра.

## Технологии
- HTML
- CSS
- JavaScript
- Без фреймворков и библиотек.

## Как запустить
1. Скачать или клонировать репозиторий.
2. Открыть `index.html` в браузере.

## Структура проекта
```
├── index.html   — разметка: поле ввода, фильтры, контейнер списка
├── index.css    — стили: зачёркивание, подсветка фильтра
└── app.js       — вся логика приложения
```
